Poki test harness

Embeds the game the way Poki does: an iframe inside a longer page that can scroll. On a phone, open the game itself instead: play full screen.

Game and canvas size (A5)

At 640x360, 836x470 and 1031x580 the game must fill the frame with no gaps and nothing stretched.

Storage (A7)

The game must still load and play. This copies what browsers do when storage is blocked in a third-party iframe. Real incognito windows are still worth a try.

Network (A8)

Play for a while, then refresh. Every request must be on this page's origin (later also the Poki SDK on game-cdn.poki.com).

Scrolling (A6)

Scroll so the game is in the middle of the screen, click into it, then use the mouse wheel, arrow keys, space, Page Up/Down, and on touch screens swipe on the game. The box at the bottom right turns red if this page moved.
